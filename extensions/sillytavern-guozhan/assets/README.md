# Bundled assets

- `Cinzel-Variable.ttf` — Cinzel display serif by Natanael Gama, SIL Open Font License 1.1
  (license text in `Cinzel-OFL.txt`). Used for the Latin display headings.
- `icons/` — selected Game-icons.net glyphs, CC BY 3.0 (see `icons/ATTRIBUTION.md`).

These assets are loaded locally by the SillyTavern extension; no runtime CDN is required.
